# Kyntek Macetero

Aplicación Android para administrar macetas inteligentes desarrolladas con ESP32-C3.

## Estado actual

Primera base del proyecto: estructura Android nativa con Kotlin y Jetpack Compose. La interfaz inicial permite crear macetas locales de demostración; todavía no se conecta al hardware ni guarda datos en un servidor.

## Tecnologías

- Kotlin
- Jetpack Compose
- Material 3
- Android Gradle Plugin

## Abrir el proyecto

Abrir la carpeta del repositorio desde Android Studio y sincronizar Gradle.

## Próximas etapas

2. Configuración Wi-Fi/Bluetooth del ESP32-C3.
3. API y almacenamiento de mediciones.
4. Alertas de humedad y batería.
